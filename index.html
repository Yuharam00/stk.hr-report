작성자 : 인사총무팀 유하람 대리

본 자료의 AS-IS(현행 프로세스) 는 담당자 구두 확인 및 정황 기반으로 작성된 미확정 정보이며, 실제 운영 프로세스와 상이할 수 있습니다. 붉은색 굵은 글씨로 표시된 항목은 현업·인사총무팀 실무 확인 및 데이터 검증이 필요합니다. 확정 전 보고자료로 사용 금지.

2

채용 프로세스 : AS-IS → TO-BE

AS-IS · 현행 (확인 필요)
1현업 채용품의서 작성
2인사총무팀 승인 (승인권자·결재라인 확인필요)
3잡코리아 개별 공고 등록
4사람인 개별 공고 등록
5지원서 채널별 개별 확인 (취합 방식 확인필요)
6면접 일정 조율 (엑셀/메일 여부 확인필요)
7합격자 관리 (통보·서류절차 확인필요)
➜
프로세스
표준화
TO-BE · 개선안
1현업 채용품의 (표준 양식)
2인사 승인
3나인하이어 Job 생성 (채용 허브 일원화)
4채용채널 연동 게시 (잡코리아·사람인 자동연동 확인완료)
5지원자 자동 수집·통합 관리
6면접 일정 관리 (캘린더 연동)
7최종합격 → 입사서류 안내
8채용 종료 후 자동 Archive (인재풀 축적)
3

핵심 이슈 및 리스크

구분현황 / 이슈개선 후업무로드확인상태
채널 운영 잡코리아·사람인 동일 공고 중복 등록 나인하이어 허브 일원화 중 -
채널 연동 잡코리아·사람인 공고게시·지원자 자동수집 정상 연동 확인 나인하이어 통합 연동 적용 하 확인완료
지원자 관리 채널별 개별 취합, 누락·중복 리스크 ATS 통합 관리, 단계별 상태 추적 중 -
데이터 자산 채용 이력·재지원자 데이터 축적 안됨 인재풀 DB화, 재조회 가능 하 -
기록 관리 탈락 사유 문서화 수준 미확인 단계별 평가근거 자동 저장 상 확인필요
4

도입 옵션 비교

A
즉시 전사 적용
무료 ATS를 전 부서·전 직군에 일괄 적용
리스크 高 — 검증 없는 전사 확대, 현업 저항 우려
B
파일럿 → 단계 확대
고빈도 채용직군 2~3개, 약 10주 시범 운영 후 확대 판단
리스크 최소화 — 실측 데이터 기반 의사결정
C
현행 유지 + 유료 ATS 검토
즉시 유료 엔터프라이즈 솔루션 도입
우선순위 낮음 — 비용 대비 검증 부족
5

실행 계획 (Option B 기준)

PHASE 1 · 2주
설계
  • 표준 채용단계 정의
  • 공고 템플릿 / 지원서 항목 표준화
  • 채용홈페이지 설계
  • 채용채널 연동 설정 (잡코리아·사람인)
PHASE 2 · 4주
파일럿 운영
  • 고빈도 채용직군 2~3개 선정 적용
  • 잡코리아·사람인 유입 테스트
  • 기존 방식과 업무시간 비교
PHASE 3 · 4주
평가 및 확대 판단
  • 채널연동·권한·자동화 한계 식별
  • 유료 전환 여부 의사결정
